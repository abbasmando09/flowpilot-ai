# FlowPilot AI

**AI-Powered Real Estate Website and Lead Management System**

FlowPilot AI is a real estate website and lead-management solution designed to help property agencies capture customer enquiries, analyze potential customers using AI, and manage leads through a private administration dashboard.

## Key Features

- Professional, responsive real estate website
- Property search and filtering
- Property details popup
- Customer enquiry form
- Google Sheets lead storage
- Gemini AI lead analysis
- Hot, Warm and Cold lead classification
- Automatic email notifications
- Private admin dashboard
- Lead search, filtering and status management

## Technology Stack

- HTML5
- CSS3
- JavaScript
- Google Apps Script
- Google Sheets
- Google Gemini API
- GitHub Pages

## Installation

Each agency requires its own Google account, Google Sheet, Apps Script backend, Gemini API key and private admin deployment.

Installation and configuration instructions will be provided separately.

## Important Security Information

- Never publish API keys or passwords in this repository.
- Keep the administration dashboard private.
- Each agency must use its own backend and customer database.
- Customer information must not be shared between agencies.

## Customization

The website can be customized with an agency's branding, logo, contact details, property listings, colors and business information.

## Product Information

FlowPilot AI is intended as a customizable website and lead-management installation for individual real estate agencies.
